# Codex2026

Мини-игра "Mini Skyline 2D" — упрощённый 2D-градостроительный симулятор в духе City Skyline.

## Запуск

Самый простой способ — открыть `index.html` в браузере.

Для локального сервера:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Управление

- Выберите инструмент слева и кликните по клетке поля.
- Бюджет расходуется на строительство и пополняется налогами.
- Электростанции дают энергию для роста населения.
- Пауза/скорость симуляции регулируется кнопками "Скорость".
